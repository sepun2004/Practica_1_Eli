# Practica 1 - Top Down

Proyecto de Unreal Engine basado en la plantilla Top Down.

## Requisitos

- Unreal Engine 5.7
- Windows

## Abrir el proyecto

1. Clona este repositorio.
2. Abre `Top_Down_Eli.uproject` con Unreal Engine 5.7.
3. Espera a que Unreal Engine termine de preparar los shaders y el contenido.

El mapa inicial del proyecto es `TopDown/Lvl_TopDown`.
